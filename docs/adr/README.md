# Architecture Decision Records

ADRs capture consequential decisions without adding a heavy RFC process.

Use the next four-digit number and include status, context, decision, and consequences. A pull request may update
an ADR's status but should not rewrite the history of an accepted decision.

| ADR | Decision |
| --- | --- |

| [0002](0002-operating-system-secret-storage.md) | Runtime secrets use the OS credential store. |
| [0003](0003-source-backed-social-ingestion.md) | Social context and linked primary sources remain distinct. |
