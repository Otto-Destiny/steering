# Support

STEERING is an early-stage open-source project.

- Use [GitHub Issues](https://github.com/Otto-Destiny/steering/issues) for reproducible bugs and focused feature or resolver requests.
- Read the documentation under [`docs/`](docs/) before opening an issue.
- Include the STEERING version, operating system, Python version, command used, and a sanitized error message.
- Never attach API keys, private posts, browser profiles, databases, or unsanitized logs.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md). General setup help is best handled in a focused
issue while the community is small; a separate support forum may be introduced if volume justifies it.
