## [0.1.0] - 2026-07-15

### Added

- Local-first Ladybug knowledge store with source snapshots, claims, evidence spans, review issues,
  project decisions, experiment outcomes, migrations, and verified logical backups.
- Public and authorized capture for social posts, repositories, papers/PDFs, webpages, uploads,
  batches, and Telegram exports.
- Evidence-validated LLM extraction, separate generation and embedding providers, OS-keyring secrets,
  and deterministic offline test providers.
- Hybrid retrieval, diverse architecture idea cards, project-history recall, web UI, JSON API, CLI,
  and Streamable HTTP MCP integration.
- Cross-platform contributor checks, security workflows, documentation, and the committed retrieval
  evaluation corpus.
